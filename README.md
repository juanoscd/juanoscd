# 📊 Quantitative Finance & Derivatives Engineer

**I develop systematic trading frameworks, risk analytics engines, and high-frequency execution pipelines for futures and derivatives markets.** Leveraging mathematical modeling, machine learning, and low-latency infrastructure, my work turns complex financial data into alpha.

---

### 🧠 Core Competencies
* **Quantitative Research:** Multi-asset alpha generation, statistical arbitrage, market microstructure, and alternative data.
* **Derivatives Modeling:** Black-Scholes, Heston Stochastic Volatility, Monte Carlo path dependency, and PDE finite differences.
* **Systematic Trading:** Term structure modeling, trend-following strategies, and basis/spread trading for global commodity and financial futures.
* **Risk Management:** Dynamic portfolio optimization, Value at Risk (VaR/CVaR), and multi-layer execution risk controls.
